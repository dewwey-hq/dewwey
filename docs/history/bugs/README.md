# Bugs

Individual bugs go in **GitHub Issues** — they need an open/closed lifecycle, which a static markdown file handles badly.

This folder is only for **recurring patterns** worth documenting once you've fixed the same shape of bug twice — the kind of thing where a doc saves real re-debugging time. Follow the style already used in `docs/engineering/places-photos.md`'s bug section: root cause, fix, and a debug checklist for next time.

Don't create a new file here for a one-off bug. If in doubt, it's a GitHub Issue.
